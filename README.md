## 🚀 Cómo publicar el programa en GitHub Pages (100% GRATIS)

En menos de 2 minutos tendrás tu enlace web funcionando para compartirlo con tu familia:

### Paso 1: Crear el repositorio en GitHub
1. Entra a [github.com](https://github.com) e inicia sesión con tu cuenta.
2. Haz clic en el botón verde **"New"** (o **"Nuevo repositorio"**).
3. Ponle de nombre: `familia-gfb` (o el nombre que prefieras).
4. Déjalo en **Public** (para que GitHub Pages sea gratis).
5. Haz clic en **"Create repository"**.

### Paso 2: Subir los archivos
1. En la página de tu nuevo repositorio, haz clic en **"uploading an existing file"** (subir archivos existentes).
2. Arrastra y suelta en la ventana los siguientes 3 archivos de esta carpeta:
   - `index.html` *(el archivo principal del programa)*
   - `manifest.json` *(para que se instale en celulares)*
   - `sw.js` *(para soporte offline y velocidad rápida)*
3. Haz clic en el botón verde **"Commit changes"**.

### Paso 3: Activar GitHub Pages
1. Dentro de tu repositorio en GitHub, ve a la pestaña superior **"Settings"** (Configuración ⚙️).
2. En el menú lateral izquierdo, haz clic en **"Pages"**.
3. En la sección **"Branch"**, cambia `None` por **`main`** (o `master`) y la carpeta déjala en `/ (root)`.
4. Haz clic en **"Save"**.

¡Listo! 🎉 En 1 minuto GitHub te dará tu enlace oficial:
👉 `https://TU_USUARIO.github.io/familia-gfb/`

## 📱 Cómo instalarlo como App en los celulares de tu familia

- **En Android (Google Chrome)**: Abre el enlace web, toca los 3 puntos arriba a la derecha y selecciona **"Instalar aplicación"** o **"Agregar a la pantalla principal"**.
- **En iPhone (Safari)**: Abre el enlace, toca el botón de compartir (el cuadrado con la flecha hacia arriba) y selecciona **"Agregar al inicio"**.
- **En Windows / Mac (Chrome o Edge)**: Haz clic en el icono de instalación en la barra de direcciones del navegador.
